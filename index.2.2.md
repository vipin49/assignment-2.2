Explanation of HTML Tags

h1 to h6 — Used to create headings of different levels.

p — Used to write paragraphs.

br — Used to insert a line break.

hr — Used to create a horizontal separator.

strong — Used to indicate important text.

em — Used to emphasize text.

i — Used to display text in italic style.

div — Used to group related content.

span — Used to organize inline content.
